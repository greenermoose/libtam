# P1: The 0.7 refactor (0.9.2 to 0.13.x)

**Status:** in progress. 0.9.2 landed on 2026-11-26; 0.10.0 is next.

## Goal

Fix libtam's unsafe core semantics, add the primitives that every
Tamlinux program currently writes for itself, and hold one copy of the
document renderer. Then move the programs onto libtam, starting with the
four that start dogfooding in Tamlinux 0.7.0: tam-edit, tam-clam,
tam-last and tam-pane. The evidence is in
[review R2](../reviews/R2-whole-suite-consumers.md).

## Decisions

Fred, 2026-11-25:

- Fix the semantics in place and migrate every caller in the same slice.
  There is no deprecation layer before 1.0.
- tam-view's renderer moves into a new optional archive,
  `libtam-render.a`.
- The shared Wayland wire module and evdev keymaps wait until after
  Tamlinux 0.7.0. They stay queued in ROADMAP.md.

## Conventions for this phase

- **Errors.** Every new or changed function returns 0 or a count on
  success, or -1 with errno set. A function that returns a pointer gives
  NULL with errno set.
- **One slice per version.** Each version is one slice, and it lands on
  Fred's acceptance.
- **Consumer edits.** Consumers that need edits get them in the same
  slice, each with its own version bump.
- **Pins.** Pinning a new libtam in `tamlinux/components.lock` waits for
  Fred's word.

## Versions

- **0.9.2: name the hardening (done).** Bump VERSION for `a3e0901`, which
  changed `tam_pager` without a bump (R2 #11). Correct the stale comments:
  - `tam_install_pending` (R1 #5);
  - the OSC 8 byte range in `tam_pager.h`;
  - the documented failure pattern for `tam_str` appends.
- **0.10.0: core semantics (breaking).**
  - **`tam_str`:** free the old buffer on failure, check for overflow,
    fix `trim` of "" and the `cat_json` leak (R2 #1).
  - **`tam_fs_read`:** an fd-based read with a size cap that refuses
    non-regular files and reads until EOF. Add `tam_fd_read_all` (R2 #2).
  - **`tam_fs_write_atomic`:** gains flags. It keeps the existing mode,
    writes through a symlink unless told to replace it, uses
    `O_CLOEXEC`, builds the temporary path dynamically, and reports
    "replaced, not durable" (R2 #3).
  - **`tam_key_feed`:** returns the number of bytes accepted (R2 #4).
  - **`tam_exec`:** the child resets signals, exec errno is reported,
    and out-of-memory is reported separately from truncation (R2 #5).
  - **Error reporting:** `tam_ini`, `tam_cultivar` and
    `tam_portal_uri_to_path` errors replace silent truncation (R2 #7).
  - **Headers:** the `tam_fs` bool functions become int with errno.
    Enums get names, printf functions get format attributes, and `tam.h`
    stops defining feature macros (R2 #6).
  - **`tam_pager`:** the external opener closes inherited descriptors
    (R1 #1).
  - **Build:** generate the version header instead of editing `tam.h`
    with `sed -i`. Add the display and session suites to `make test`, and
    install `libtam.pc`.
  - **Consumers:** migrate every caller of the changed functions. tam-edit
    and tam-data pass the keep-mode flag when saving user files.
- **0.11.0: process, I/O, socket and small primitives.** Each new module
  comes from the best existing copy (R2 #8):
  - **`tam_proc`:** `tam_which`, `tam_spawn_detached` (the external
    opener is rebuilt on it) and `tam_run_foreground`.
  - **`tam_io`:** `tam_write_all` and `tam_read_line`.
  - **`tam_time`:** a monotonic clock.
  - **`tam_path` additions:** `tam_xdg_base`, a data-directories
    iterator, and `tam_runtime_dir` with owner and mode checks.
  - **`tam_sock`:** a private listener that refuses a live socket, a
    peer-uid check, connect with a timeout, and a line reader with a
    deadline for the whole request.
  - **`tam_uni` additions:** `tam_utf8_prev`, `tam_utf8_valid` and
    `tam_locale_init` with a `C.UTF-8` fallback.
  - **`tam_b64`:** base64, with an OSC 52 copy helper.
  - **`tam_install_guard`:** prints the standard message and treats a
    probe error as an error.
  - **JSON:** quoted-string and key-value helpers.
- **0.12.0: terminal stack.**
  - **`tam_tty` suspend and resume:** around a child or Ctrl+Z.
  - **`tam_tty_install_restore`:** an async-signal-safe restore on fatal
    signals, followed by re-raising the signal.
  - **A self-pipe resize wake-up.**
  - **`tam_tty_cbreak`.**
  - **`tam_tty_read`:** returns a distinct end-of-file value.
  - **`tam_key` events:** bracketed-paste and SGR-mouse events.
  - **`tam_key_name_parse`/`format`:** with one rule for Shift.
- **0.13.0: `libtam-render.a`.**
  - Move tam-view's renderer into `src/render/` with `tam_render.h`,
    starting from tam-view's newer `source.c`.
  - Prefix the exported symbols.
  - Delete the copies in tam-view and tam-knox.
- **0.13.x: consumer migrations.** Each program is its own slice, in this
  order:
  1. tam-edit
  2. tam-clam
  3. tam-last
  4. tam-pane
  5. tam-view and tam-knox
  6. tam-data
  7. the tamlinux commands
  8. tam and tamlinux-tools
  9. tam-hide, last, because it is 0.8 scope.

  Each slice deletes the local copy, fixes the consumer bugs that R2
  lists for that program, and sets the program's libtam version floor and
  relink prerequisite. A libtam fix found during migration is a patch
  release.

## Acceptance

- **libtam:** `make test` passes under ASan and UBSan, including the
  display, session and render suites. Each changed or new function has
  tests:
  - `tam_fs_read`: a FIFO, `/proc/self/status`, a pipe, a file over the
    cap, and a directory;
  - `tam_fs_write_atomic`: keeps 0755 and 0600, and writes through a
    symlink;
  - `tam_str`: allocation failure;
  - `tam_key_feed`: partial accepts;
  - `tam_exec`: a blocked signal mask and a missing program;
  - `tam_ini`: error lines.
- **tam-bud:** its check that `tam` links libtam statically still passes.
- **Each migrated consumer:**
  - `make test` passes, and it installs with
    `make install PREFIX=$HOME/.local`;
  - `command -v` resolves to the development build.
- **tamlinux:** `desktop/check-all` passes without `--proofs`.
- **Fred's hands-on checks:**
  - tam-edit keeps a script's `+x` and a 0600 file's mode, and leaves a
    symlink in place.
  - A 300-byte paste reaches tam-knox as a paste.
  - Killing tam-edit, tam-knox or tam-view leaves a sane terminal.
  - `tam-pane msg subscribe | head -1` exits.
  - tam-data aligns CJK columns.

## Dependencies

- **`libtam.a`:** still needs only libc.
- **`libtam-render.a`:** needs only `libtam.a`.
- **Unchanged:** no new third-party code, and the portal and display
  archives are unchanged.
- **Records to update:** each consumer's `arch/dependencies.md`, and
  tam-knox's `UPSTREAM.md` entry for the renderer copy, which is removed.

## Risks

- **Breaking changes reach programs other agents are working on.**
  - Mitigation: claim each consumer's paths, check the inboxes first, and
    land a libtam version and its caller edits in one slice.
  - Consumers build against an exact libtam, so an unmigrated consumer
    keeps its pin until its slice.
- **`tam_str`'s new free-on-failure rule could cause a double free.** A
  caller that keeps the old pointer after a failed append would free it a
  second time.
  - Mitigation: audit every caller in the same slice for that pattern
    before changing the rule.
- **Writing through symlinks changes what tam-edit does to a symlinked
  file.**
  - This is the intended fix, but Fred should see it once in the
    hands-on check.
- **A crash-time terminal restore must be async-signal-safe.**
  - Mitigation: restore only with `tcsetattr` and `write` of fixed
    strings, then re-raise the signal.

## Open points

- None. Fred decided the three choices on 2026-11-25.
