- **Date** 2026-11-11

> Approve tam nut development; continue integration

Libtam 0.6.0 adds a bounded, read-only startup barrier for native Tamlinux
commands. It refuses an applying or activating system transaction and
malformed, untrusted or unreadable format-2 records. An explicit path
supports isolated fixtures. The default path retains compatibility with
the earlier real-directory slot and its root-private state.

The sanitizer suite passed outside the agent sandbox, including state,
duplicate-field, format, permission, link, FIFO and size-limit cases.
The API supports the public bundle delivery plan. Package installation
and workstation acceptance remain separate.
